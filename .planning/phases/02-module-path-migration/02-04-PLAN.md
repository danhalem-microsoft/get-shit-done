init.cjs has the MOST `.planning/` references (~80). Every `cmdInit*` function already has `ctx = tryGetPlanningContext(cwd)` from Phase 1. Migrate the first 7 cmdInit functions.

**Migration pattern for path existence checks:**
```javascript
// BEFORE
state_exists: pathExistsInternal(cwd, '.planning/STATE.md'),

// AFTER
state_exists: ctx.planning_root
  ? pathExistsInternal(cwd, path.join(ctx.planning_root, 'STATE.md'))
  : false,
```

**Migration pattern for path output values:**
```javascript
// BEFORE
state_path: '.planning/STATE.md',

// AFTER
state_path: ctx.planning_root ? `${ctx.planning_root}/STATE.md` : null,
```

**Migration pattern for file reads:**
```javascript
// BEFORE
const state = safeReadFile(path.join(cwd, '.planning', 'STATE.md'));

// AFTER
const state = ctx.planning_root
  ? safeReadFile(path.join(cwd, ctx.planning_root, 'STATE.md'))
  : null;
```

**Null planning_root handling (CRITICAL — Pitfall 3):**
When `ctx.planning_root` is null (no active project), ALL path-derived values must be null or false. Never construct `path.join(cwd, null, 'STATE.md')` — it produces garbage paths.

**Functions to migrate in this task (first 7):**
Go through the first ~7 cmdInit functions (e.g., `cmdInitPlanPhase`, `cmdInitExecutePhase`, `cmdInitDiscussPhase`, `cmdInitResearchPhase`, `cmdInitNewProject`, `cmdInitMapCodebase`, `cmdInitVerifyWork`). Each follows the same pattern:
1. ctx is already available from Phase 1
2. Replace hardcoded `.planning/` path segments with `ctx.planning_root`
3. Guard with `ctx.planning_root ?` for null safety
4. path_exists fields → false when no planning_root
5. path output fields → null when no planning_root

**Special cases:**
- `cmdInitPlanPhase` — has `phase_dir` that constructs `.planning/phases/XX-name`. Use `ctx.planning_root + '/phases/' + ...`
- `cmdInitExecutePhase` — similar phase_dir construction
- `cmdInitMapCodebase` — may have `.planning/codebase/` references
- `cmdInitNewProject` — may not need planning_root (creating new project). Check carefully — if creating a new project, the paths come from the new project context, not the current one.

**Null safety verification checklist (apply to EVERY function migrated):**
- [ ] Every `path.join(cwd, '.planning', ...)` is guarded with `ctx.planning_root ?`
- [ ] Every `pathExistsInternal(cwd, '.planning/...')` returns `false` when `ctx.planning_root` is null
- [ ] Every path output value (e.g., `state_path`, `phase_dir`) returns `null` when `ctx.planning_root` is null
- [ ] Every `safeReadFile(path.join(cwd, '.planning', ...))` returns `null` when `ctx.planning_root` is null
- [ ] No `path.join(cwd, null, ...)` or `path.join(cwd, undefined, ...)` is possible

**Test updates (tests/init.test.cjs — first half):**
1. Replace `createTempProject()` with `createTempMultiUserProject()` — destructure `{ tmpDir, userSlug, projectName }` and compute `planningRoot = '.planning/users/' + userSlug + '/' + projectName`
