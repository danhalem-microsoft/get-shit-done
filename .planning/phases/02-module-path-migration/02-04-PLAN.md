<task type="auto">
  <name>Task 1: Migrate init.cjs from hardcoded paths to planning_root</name>
  <files>get-shit-done/bin/lib/init.cjs, tests/init.test.cjs</files>
  <action>
init.cjs has the MOST `.planning/` references (~80). Every `cmdInit*` function already has `ctx = tryGetPlanningContext(cwd)` from Phase 1. The migration pattern is:

**For path existence checks:**
```javascript
// BEFORE
state_exists: pathExistsInternal(cwd, '.planning/STATE.md'),

// AFTER
state_exists: ctx.planning_root
  ? pathExistsInternal(cwd, path.join(ctx.planning_root, 'STATE.md'))
  : false,
```

**For path output values:**
```javascript
// BEFORE
state_path: '.planning/STATE.md',

// AFTER
state_path: ctx.planning_root ? `${ctx.planning_root}/STATE.md` : null,
```

**For file reads:**
```javascript
// BEFORE
const state = safeReadFile(path.join(cwd, '.planning', 'STATE.md'));

// AFTER
const state = ctx.planning_root
  ? safeReadFile(path.join(cwd, ctx.planning_root, 'STATE.md'))
  : null;
```

**Null planning_root handling (CRITICAL — Pitfall 3):**
When `ctx.planning_root` is null (no active project), ALL path-derived values must be null or false. Never construct `path.join(cwd, null, 'STATE.md')` — it produces garbage paths.

**All 13 cmdInit* functions to migrate:**
Go through each function systematically. Most follow the same pattern:
1. ctx is already available from Phase 1
2. Replace hardcoded `.planning/` path segments with `ctx.planning_root`
3. Guard with `ctx.planning_root ?` for null safety
4. path_exists fields → false when no planning_root
5. path output fields → null when no planning_root

**Special cases in init.cjs:**
- `cmdInitPlanPhase` — has `phase_dir` that constructs `.planning/phases/XX-name`. Use `ctx.planning_root + '/phases/' + ...`
- `cmdInitExecutePhase` — similar phase_dir construction
- `cmdInitMapCodebase` — may have `.planning/codebase/` references
- `cmdInitNewProject` — may not need planning_root (creating new project). Check carefully.

**Test updates (tests/init.test.cjs — 84 refs):**
1. Replace `createTempProject()` with `createTempMultiUserProject()`
2. Update all `path.join(tmpDir, '.planning', ...)` to multi-user paths
3. Update assertion strings that check output paths (e.g., `state_path` should now show `.planning/users/<user>/<project>/STATE.md`)
4. Add `clearPlanningRootCache()` in test teardown
5. Test null planning_root scenarios (no active project → paths are null)
