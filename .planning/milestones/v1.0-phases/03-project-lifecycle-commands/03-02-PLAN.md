  <name>Task 1: Create cmdInitSwitch and cmdInitProjectSetup init commands</name>
  <files>get-shit-done/bin/lib/init.cjs, tests/init.test.cjs</files>
  <behavior>
    - cmdInitSwitch(cwd, projectArg, raw) with a project arg returns switch result with project details
    - cmdInitSwitch(cwd, null, raw) without project arg returns list of projects with metadata
    - cmdInitSwitch errors when specified project not found, with available project suggestions
    - cmdInitSwitch with fuzzy matching finds partial matches (substring/prefix)
    - cmdInitSwitch(cwd, projectArg, raw) writes .active context when project is found
    - cmdInitProjectSetup(cwd, raw) returns user identity + existing projects list WITHOUT requiring an active project
    - cmdInitProjectSetup returns global config for seeding new project config
  </behavior>
  <action>
    1. **Create `cmdInitSwitch(cwd, projectArg, raw)`** in init.cjs:
       - Resolve identity via `resolveIdentity(cwd)` — hard-error if null
       - Call `listProjects(cwd, user)` to get structured project array
       - If `projectArg` is provided:
         - Try exact slug match first: `projects.find(p => p.name === projectArg)`
         - If no exact match, try fuzzy: `projects.filter(p => p.name.includes(projectArg))`
         - If exactly 1 fuzzy match, use it
         - If 0 matches: `error('GSD Error: Project "' + projectArg + '" not found. Available: ' + projects.map(p => p.name).join(', '))`
         - If multiple fuzzy matches: `error('GSD Error: Ambiguous match for "' + projectArg + '". Matches: ' + matches.map(p => p.name).join(', '))`
         - Call `writeActiveContext(cwd, user, matched.name)` to set active
         - Return: `{ switched: true, project: matched.name, planning_root: ... }`
       - If `projectArg` is null/undefined:
         - Return: `{ switched: false, projects: [...], user }` (listing mode)
       - Result always has context fields first: `active_user`, `active_project`, `planning_root`

    2. **Create `cmdInitProjectSetup(cwd, raw)`** in init.cjs:
       - This is the lightweight pre-init for new-project two-step bootstrap
       - Call `resolveIdentity(cwd)` directly — hard-error if null
       - Scan for existing projects: `listProjects(cwd, user)`
       - Read global config: `safeReadFile(path.join(cwd, '.planning', 'config.json'))`
       - Do NOT call `tryGetPlanningContext()` or `getPlanningRoot()` — this runs before any project exists
       - Ensure `.planning/users/<user>/` directory exists
       - Return: `{ user, projects: [...], global_config: parsedConfig || {}, planning_exists: fs.existsSync(...) }`

    3. **Create `cmdArchiveProject(cwd, projectArg, raw)` and `cmdRestoreProject(cwd, projectArg, raw)`** in init.cjs:
       - Archive: move `<userDir>/<project>` to `<userDir>/_archived/<project>/` using `fs.renameSync`
         - Create `_archived/` if it doesn't exist
         - If the archived project was active (check .active file), clear .active and auto-select another project if exactly one remains
         - Error if project doesn't exist or is already archived
       - Restore: move `<userDir>/_archived/<project>` back to `<userDir>/<project>`
         - Error if project not found in _archived/
         - Error if a project with that name already exists in active directory
         - Set restored project as active via `writeActiveContext()`
       - Both return structured results with context fields

    4. **Write tests** (extend init.test.cjs):
       - Test cmdInitSwitch with exact match
       - Test cmdInitSwitch with fuzzy match (substring)
       - Test cmdInitSwitch with no match (error)
       - Test cmdInitSwitch without args (listing mode)
       - Test cmdInitSwitch writes .active on successful switch
       - Test cmdInitProjectSetup returns user + project list
       - Test cmdInitProjectSetup works without any existing projects
       - Test cmdArchiveProject moves directory to _archived/
       - Test cmdArchiveProject clears .active when archiving active project
       - Test cmdRestoreProject moves directory from _archived/ back
       - Test cmdRestoreProject errors on duplicate name

    5. **Export** all new functions from init.cjs module.exports
