# Plan 01-02: Context Module and getPlanningRoot

**Goal:** Create `context.cjs` — the active project context management module — and add `getPlanningRoot()` + `tryGetPlanningContext()` to `core.cjs`. Together these provide the single chokepoint for resolving user-qualified planning paths. Also includes CI/CD detection, old flat-structure detection, and gitignore management for `.active` files.

## Tasks

<task id="01-02-01" name="Create context.cjs module" files="get-shit-done/bin/lib/context.cjs">
<action>
Create `get-shit-done/bin/lib/context.cjs` with these exported functions:

### `readActiveContext(cwd, user)`
- Build path: `path.join(cwd, '.planning', 'users', user, '.active')`
- Use `safeReadFile()` from `core.cjs` to read the file
- If null (file missing), return `null`
- Try `JSON.parse()` on content
- If parse fails or parsed object has no `.project` field, return `null`
- Return parsed object: `{ project, resolved_path }`

### `writeActiveContext(cwd, user, project)`
- Build user dir: `path.join(cwd, '.planning', 'users', user)`
- Create user directory if it doesn't exist: `fs.mkdirSync(userDir, { recursive: true })`
- Build resolved_path using `toPosixPath`: `toPosixPath(path.join('.planning', 'users', user, project))`
- Write `.active` file: `JSON.stringify({ project, resolved_path }, null, 2) + '\n'`
- After writing `.active`, call `ensureActiveGitignored(cwd)` to ensure gitignore coverage

### `ensureActiveGitignored(cwd)`
Internal helper (not exported). Ensures `.active` files are gitignored:
- Read `path.join(cwd, '.gitignore')` using `safeReadFile()`
- If file exists and already contains the line `**/.active` (check with regex or string includes), do nothing
- If file doesn't exist or doesn't contain the pattern:
  - Append `\n# GSD active project context (per-user, machine-specific)\n**/.active\n` to the file
  - If file doesn't exist, create it with just that content
- This is a defensive measure for downstream repos that commit `.planning/` artifacts

### `resolveContext(cwd)`
The main entry point that combines identity resolution with active context.

Returns `{ user, project, planning_root }` or calls `error()` on hard failure.

**Resolution logic:**

1. **Resolve user identity:**
   - `const { resolveIdentity } = require('./identity.cjs')`
   - `const identity = resolveIdentity(cwd)`
   - If identity is null: call `error('GSD Error: Cannot resolve user identity. Set git user.name or GSD_USER environment variable.')`
   - Extract `user = identity.slug`

2. **Ensure user directory exists:**
   - `const userDir = path.join(cwd, '.planning', 'users', user)`
   - `fs.mkdirSync(userDir, { recursive: true })` -- bootstraps on first use

3. **Resolve project (env var override first):**
   - Check `process.env.GSD_PROJECT`
   - If set and non-empty, use it directly as the project name (transient, does NOT persist to .active)
   - Validate: check if `path.join(cwd, '.planning', 'users', user, envProject)` exists as a directory
   - If directory doesn't exist: call `error('GSD Error: Project "' + envProject + '" not found for user ' + user + '. Available projects: ' + listProjects(cwd, user))`
   - Otherwise: project = envProject

4. **If no GSD_PROJECT env var, read .active file:**
   - `const active = readActiveContext(cwd, user)`
   - If active is null (no .active file): call `error('GSD Error: No active project. Run /gsd:new-project to create one, or /gsd:switch to select one.')`
   - Validate: check if the project directory exists at `path.join(cwd, '.planning', 'users', user, active.project)`
   - If directory doesn't exist: call `error('GSD Error: Active project "' + active.project + '" not found. Run /gsd:switch to select a valid project.')`
   - Otherwise: project = active.project

5. **Build and return result:**
   ```javascript
   const planning_root = toPosixPath(path.join('.planning', 'users', user, project));
   return { user, project, planning_root };
   ```

### `listProjects(cwd, user)` (internal helper, not exported)
- Read directory entries at `path.join(cwd, '.planning', 'users', user)`
- Filter to directories only (exclude `.active` file, `_archived` dir)
- Return comma-separated string of project names, or `'(none)'` if empty

### `getPlanningRoot(cwd)`
The single chokepoint for all path resolution. Returns the user-qualified planning directory string (e.g., `.planning/users/dan-halem/frontend`).

**Check order (critical):**

1. **CI/CD detection (hard error, first check):**
   ```javascript
   const ciVars = ['CI', 'GITHUB_ACTIONS', 'GITLAB_CI', 'JENKINS_URL', 'CIRCLECI', 'TRAVIS'];
   if (ciVars.some(v => process.env[v])) {
     error('GSD Error: CI/CD environment detected. GSD is not supported in CI.');
   }
   ```

2. **Old flat structure detection (hard error):**
   ```javascript
   if (fs.existsSync(path.join(cwd, '.planning', 'PROJECT.md')) &&
       !fs.existsSync(path.join(cwd, '.planning', 'users'))) {
     error('GSD Error: Legacy .planning/ structure detected. To start fresh: Remove .planning/ and run /gsd:new-project. To preserve work: Move your files to .planning/users/<your-slug>/<project-name>/');
   }
   ```
   Both conditions must be true: PROJECT.md exists AND users/ does NOT exist. If users/ exists alongside PROJECT.md, it's the new structure -- no error.

3. **Delegate to context.cjs (lazy require):**
   ```javascript
   const { resolveContext } = require('./context.cjs');
   const ctx = resolveContext(cwd);
   return ctx.planning_root;
   ```
   CRITICAL: Use lazy require inside the function body, NOT at module scope. This avoids circular dependency: core.cjs -> context.cjs -> core.cjs. By the time `getPlanningRoot()` is called, all modules are fully loaded.

**Memoization:**
- Cache the result in a module-level variable keyed by `cwd`
- On subsequent calls with the same `cwd`, return cached value
- Declare cache at module level: `let _planningRootCache = {};`
- Check cache first: `if (_planningRootCache[cwd]) return _planningRootCache[cwd];`
- Set cache after resolution: `_planningRootCache[cwd] = ctx.planning_root;`
- Export a `clearPlanningRootCache()` function for test use

### `tryGetPlanningContext(cwd)`
Safe wrapper for init commands that may run before a project exists. Returns `{ active_user, active_project, planning_root }` with null fields on graceful failure. CI/CD and old-structure errors still propagate as hard errors.

```javascript
function tryGetPlanningContext(cwd) {
  // CI/CD and old-structure checks still hard-error
  const ciVars = ['CI', 'GITHUB_ACTIONS', 'GITLAB_CI', 'JENKINS_URL', 'CIRCLECI', 'TRAVIS'];
  if (ciVars.some(v => process.env[v])) {
    error('GSD Error: CI/CD environment detected. GSD is not supported in CI.');
  }
  if (fs.existsSync(path.join(cwd, '.planning', 'PROJECT.md')) &&
      !fs.existsSync(path.join(cwd, '.planning', 'users'))) {
    error('GSD Error: Legacy .planning/ structure detected. To start fresh: Remove .planning/ and run /gsd:new-project. To preserve work: Move your files to .planning/users/<your-slug>/<project-name>/');
  }

  try {
    const { resolveContext } = require('./context.cjs');
    const ctx = resolveContext(cwd);
    return { active_user: ctx.user, active_project: ctx.project, planning_root: ctx.planning_root };
  } catch {
    return { active_user: null, active_project: null, planning_root: null };
  }
}
```

Note: The `try/catch` catches errors from `resolveContext` (which calls `error()` -> `process.exit(1)`). However, since `error()` calls `process.exit(1)`, the catch won't actually catch it in production. The safety is for cases where `resolveIdentity` returns null before error() is called, or where .active doesn't exist. **Actually, since error() calls process.exit(), we need a different approach:**

Revised approach: `tryGetPlanningContext` should attempt identity resolution separately and catch at a higher level. Use a modified flow:

```javascript
function tryGetPlanningContext(cwd) {
  // CI/CD check (hard error - these are always fatal)
  const ciVars = ['CI', 'GITHUB_ACTIONS', 'GITLAB_CI', 'JENKINS_URL', 'CIRCLECI', 'TRAVIS'];
  if (ciVars.some(v => process.env[v])) {
    error('GSD Error: CI/CD environment detected. GSD is not supported in CI.');
  }
  // Old structure check (hard error)
  if (fs.existsSync(path.join(cwd, '.planning', 'PROJECT.md')) &&
      !fs.existsSync(path.join(cwd, '.planning', 'users'))) {
    error('GSD Error: Legacy .planning/ structure detected. To start fresh: Remove .planning/ and run /gsd:new-project. To preserve work: Move your files to .planning/users/<your-slug>/<project-name>/');
  }

  // Soft resolution -- return nulls instead of hard erroring
  const { resolveIdentity } = require('./identity.cjs');
  const { readActiveContext } = require('./context.cjs');

  const identity = resolveIdentity(cwd);
  if (!identity) {
    return { active_user: null, active_project: null, planning_root: null };
  }

  const user = identity.slug;
  const envProject = process.env.GSD_PROJECT;
  let project = null;
  let planning_root = null;

  if (envProject) {
    const projectDir = path.join(cwd, '.planning', 'users', user, envProject);
    if (fs.existsSync(projectDir)) {
      project = envProject;
    }
  } else {
    const active = readActiveContext(cwd, user);
    if (active && active.project) {
      const projectDir = path.join(cwd, '.planning', 'users', user, active.project);
      if (fs.existsSync(projectDir)) {
        project = active.project;
      }
    }
  }

  if (project) {
    planning_root = toPosixPath(path.join('.planning', 'users', user, project));
  }

  return { active_user: user, active_project: project, planning_root };
}
```

This way: CI/CD and old-structure checks hard-error (via `error()`), but identity/context failures return null fields gracefully without calling `error()`.
