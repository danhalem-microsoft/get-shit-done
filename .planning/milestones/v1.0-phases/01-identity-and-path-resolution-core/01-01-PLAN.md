# Plan 01-01: Identity Module

**Goal:** Create `identity.cjs` — the user identity resolution module that resolves a git identity to a filesystem-safe slug, manages the `user-map.json` identity registry, and supports `GSD_USER` env var override. Also create the `createTempMultiUserProject()` test helper and comprehensive identity tests.

## Tasks

<task id="01-01-01" name="Create identity.cjs module" files="get-shit-done/bin/lib/identity.cjs">
<action>
Create `get-shit-done/bin/lib/identity.cjs` with these exported functions:

### `sanitizeSlug(raw)`
- Call `generateSlugInternal(raw)` from `core.cjs` for base slug generation (lowercase, hyphens, alphanumeric)
- If result is null/empty, return null
- Enforce 30-character max: `base.substring(0, 30).replace(/-+$/, '')` to trim trailing hyphens after truncation
- Return the final slug string

### `loadUserMap(cwd)`
- Build path: `path.join(cwd, '.planning', 'user-map.json')`
- Use `safeReadFile()` from `core.cjs` to read the file
- If null (file missing), return empty object `{}`
- Try `JSON.parse()` on the content
- On parse failure (corrupted JSON): write warning to stderr `process.stderr.write('Warning: user-map.json corrupted, re-registering identity.\n')` and return `{}`
- Return the parsed object

### `lockIdentity(cwd, raw, slug)`
- Call `loadUserMap(cwd)` to get current map
- If `map[raw]` already exists, return `map[raw]` (first registration wins)
- Collect all existing slug values: `new Set(Object.values(map).filter(v => typeof v === 'string'))`
- If `slug` is already taken, append numeric suffix: try `slug-2`, `slug-3`, etc. until unique
- Set `map[raw] = finalSlug`
- Write map back: `fs.writeFileSync(mapPath, JSON.stringify(map, null, 2) + '\n', 'utf-8')`
- Print registration message to stderr: `process.stderr.write('GSD: Registered user ' + finalSlug + ' (from ' + source + ')\n')`
- Return `finalSlug`

Note: `lockIdentity` needs a `source` parameter for the registration message. Add it as a 4th parameter: `lockIdentity(cwd, raw, slug, source)`.

### `resolveIdentity(cwd)`
Returns `{ slug, source, raw }` or `null` if all sources fail.

Resolution chain (each step only tried if previous is empty/unset):

1. **GSD_USER env var** — `process.env.GSD_USER`. If set and non-empty, return `{ slug: envUser, source: 'GSD_USER', raw: envUser }`. Direct slug, no sanitization, no user-map.json interaction. Transient override.

2. **git config user.name** — Call `execGit(cwd, ['config', 'user.name'])`. If `exitCode === 0` and `stdout.trim()` is non-empty:
   - `raw = stdout.trim()`
   - `slug = sanitizeSlug(raw)`
   - If slug is null, skip to next source
   - Call `lockIdentity(cwd, raw, slug, 'git user.name')` to get final slug (handles collision suffix)
   - Return `{ slug: finalSlug, source: 'git-user-name', raw }`

3. **git config user.email local-part** — Call `execGit(cwd, ['config', 'user.email'])`. If `exitCode === 0` and `stdout.trim()` is non-empty:
   - Extract local part: `stdout.trim().split('@')[0]`
   - If local part is non-empty:
     - `raw = localPart`
     - `slug = sanitizeSlug(raw)`
     - If slug is null, skip to next source
     - Call `lockIdentity(cwd, raw, slug, 'git user.email')` to get final slug
     - Return `{ slug: finalSlug, source: 'git-user-email', raw }`

4. **OS username** — Wrap in try/catch (can throw `SystemError` in Docker containers without `/etc/passwd`):
   - `const username = require('os').userInfo().username`
   - If non-empty:
     - `raw = username`
     - `slug = sanitizeSlug(raw)`
     - If slug is null, skip to next source
     - Call `lockIdentity(cwd, raw, slug, 'os-username')` to get final slug
     - Return `{ slug: finalSlug, source: 'os-username', raw }`

5. **All failed** — return `null`. The caller (`getPlanningRoot` in core.cjs) will call `error()` to hard-exit.

### Module structure
Follow the exact module template from CONVENTIONS.md:
```javascript
/**
 * Identity -- User identity resolution and slug management
 */

const fs = require('fs');
const path = require('path');
const { execGit, generateSlugInternal, safeReadFile } = require('./core.cjs');

// --- Identity Resolution ---------------------------------------------------

function sanitizeSlug(raw) { /* ... */ }
function resolveIdentity(cwd) { /* ... */ }

// --- User Map Management ---------------------------------------------------

function loadUserMap(cwd) { /* ... */ }
function lockIdentity(cwd, raw, slug, source) { /* ... */ }

module.exports = {
  sanitizeSlug,
  resolveIdentity,
  loadUserMap,
  lockIdentity,
};
```

Key constraints:
- **No `cmd*` prefix** — these are internal plumbing functions, not CLI dispatch targets
- **Synchronous only** — no async/await or Promises
- **No `error()` calls** — utility functions return null on failure; caller handles hard errors
- **No auto-creation of `.planning/` directory** — if `.planning/` doesn't exist, GSD hasn't been initialized; that's handled by new-project (Phase 3)
- **user-map.json includes `_schema: 1`** — add when creating a new map. `loadUserMap()` should filter `_schema` key when iterating entries (it's metadata, not a user mapping)

<task id="01-01-02" name="Add createTempMultiUserProject to test helpers" files="tests/helpers.cjs">
<action>
Add a `createTempMultiUserProject(opts)` function to `tests/helpers.cjs` and export it.

**Function signature:** `createTempMultiUserProject(opts = {})`

**Options with defaults:**
```javascript
const {
  userName = 'Test User',
  userEmail = 'test@test.com',
  userSlug = 'test-user',
  projectName = 'test-project',
  withActive = true,
} = opts;
```

**Implementation:**
1. Create temp directory: `fs.mkdtempSync(path.join(os.tmpdir(), 'gsd-test-'))`
2. Create directory structure: `fs.mkdirSync(path.join(tmpDir, '.planning', 'users', userSlug, projectName, 'phases'), { recursive: true })`
3. Initialize git repo:
   - `execSync('git init', { cwd: tmpDir, stdio: 'pipe' })`
   - `execSync('git config user.email "${userEmail}"', ...)`
   - `execSync('git config user.name "${userName}"', ...)`
4. Create `user-map.json`: `{ "_schema": 1, [userName]: userSlug }` at `.planning/user-map.json`
5. If `withActive`, create `.active` file at `.planning/users/<userSlug>/.active`:
   ```json
   { "project": "<projectName>", "resolved_path": ".planning/users/<userSlug>/<projectName>" }
   ```
6. Create `.gitignore` with `**/.active\n` pattern
7. Create initial commit: `git add -A && git commit -m "initial commit"`
8. Return `{ tmpDir, userSlug, projectName }`

**Update `module.exports`** to include `createTempMultiUserProject`.

**Important:** Do NOT modify the existing `createTempProject`, `createTempGitProject`, or `runGsdTools` functions. Only ADD the new helper.
