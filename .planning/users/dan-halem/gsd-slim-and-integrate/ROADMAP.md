# Roadmap: GSD Slim + SP Integration + TDD Hardening

## Overview

A coordinated trim-and-integrate pass on GSD itself, executed in six dependency-ordered phases. Phase 1 builds parity infrastructure (Wave 0) before culling 49 commands and 17 agents and consolidating `/gsd-review` and `/gsd-phase`. Phase 2 verifies `@`-reference resolution in agent context (commit 0 spike) before extracting the shared critic base and converting the 6 critics to lens addendums fired as a single parallel batch. Phase 3 merges `gsd-research-synthesizer` into `gsd-planner` and parallelizes pattern-mapper + phase-researcher, with a token-headroom gate that escalates to Posture B trim of the planner specifically if the merged prompt crosses 100K tokens. Phase 4 lands all three TDD layers (executor + planner prompt rules, plan-checker structural rule, `hooks/tdd-gate.sh`) with 30-day warn-mode auto-sunset and CI mirror. Phase 5 wires `--from-spec` into the three GSD entry points, ships the project-local SP brainstorming addendum via `CLAUDE.md` `@`-import, and runs a nightly contract test against the live SP brainstorming skill. Phase 6 trims each surviving spine agent ≥10% (Posture A) against Phase 1 wave 0 baselines, with parity tests using N=5 median and severity-stratified thresholds.

Each phase ends with a git tag (`gsd-slim-phase-N-<name>`) created only after both static and live test suites for that phase pass. The walltime ledger accumulates one JSONL entry per live test invocation across all phases; Phase 6 introduces the trend regression test once enough data has accumulated.
