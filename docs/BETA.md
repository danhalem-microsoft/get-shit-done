# GSD Beta Features

> **Beta features are opt-in and may change or be removed without notice.** They are not covered by the stable API guarantees that apply to the rest of GSD. If a beta feature ships to stable, it will be documented in [COMMANDS.md](COMMANDS.md) and [FEATURES.md](FEATURES.md) with a changelog entry.

---

## No active beta features

The Phase 1 cull (commit-stamp-anchored to milestone v1.38) retired the previous beta entries (the cloud-side ultraplan integration and the external-plan import command). There are no replacement beta features at the moment.

When new beta features land, this page is repopulated with role cards in the same format used previously: a one-line tagline, runtime requirements, usage examples, what-gets-produced, and a troubleshooting subsection.
